חיבור {{mcp.name}} ל-Claude.

חמישה צעדים, בלי התקנה מקומית. מוסיפים את השרת כמחבר ב-Claude, מאשרים את הגישה בחלון שנפתח, ומתחילים לעבוד על השרטוט מתוך שיחה.

מה צריך לפני שמתחילים

  • חשבון Claude בתוכנית שתומכת במחברים מותאמים (Pro, Max, Team או Enterprise), או Claude Code במסוף.
  • חשבון Pro Algorithm. איתו נכנסים בחלון האישור בשלב 4.
  • AutoCAD פתוח עם השרטוט שרוצים לעבוד עליו.

חיבור ב-Claude (אתר או אפליקציה)

  1. פותחים את ההגדרות. לוחצים על שם המשתמש בפינה, בוחרים Settings ואז Connectors.
  2. מוסיפים מחבר. גוללים לתחתית הרשימה ולוחצים Add custom connector.
  3. ממלאים את הפרטים. בשדה השם כותבים AutoCAD MCP, ובשדה הכתובת מדביקים: 
    {{mcp.server}}
    לוחצים Add. אין צורך למלא Client ID או Client Secret, השרת רושם את Claude בעצמו.
  4. מאשרים את הגישה. ליד המחבר החדש לוחצים Connect. נפתח חלון של Pro Algorithm בכתובת {{mcp.authorize}}. נכנסים עם חשבון Pro Algorithm ומאשרים את ההרשאה autocad. בסיום החלון נסגר והמחבר מסומן כמחובר.
  5. מפעילים בשיחה. פותחים שיחה חדשה, לוחצים על כפתור הכלים (+ או Search and tools) ומוודאים ש-AutoCAD MCP מסומן. עכשיו אפשר לשאול, למשל: "אילו שכבות יש בשרטוט הפתוח?"

חיבור ב-Claude Code

במסוף, מתוך תיקיית הפרויקט:

claude mcp add --transport http autocad {{mcp.server}}

מריצים claude, מקלידים /mcp, בוחרים autocad ואז Authenticate. הדפדפן נפתח לאותו חלון אישור, ואחרי האישור הכלים זמינים בשיחה.

מה Claude יכול לעשות אחרי החיבור

  • לקרוא את השרטוט: שכבות, בלוקים, ישויות ומאפיינים, ולענות על שאלות מתוך הנתונים עצמם.
  • לבצע שינויים: יצירה ועריכה של ישויות, סידור שכבות, עדכון בלוקים.
  • לבקש אישור לפני פעולות. ב-Claude אפשר לקבוע לכל כלי אם הוא רץ אוטומטית או מבקש אישור בכל פעם.

פתרון בעיות

  • חלון האישור לא נפתח. הדפדפן חסם חלון קופץ. מאשרים חלונות קופצים ל-claude.ai ולוחצים Connect שוב.
  • המחבר מחובר אבל Claude לא רואה כלים. בודקים ש-AutoCAD פתוח ושיש בו שרטוט פעיל, ואז פותחים שיחה חדשה.
  • שגיאת invalid_token או 401. ההרשאה פגה. ב-Settings, Connectors לוחצים על המחבר, Disconnect, ואז Connect מחדש.
  • הכלים לא מופיעים בשיחה קיימת. מחברים חדשים נטענים רק בשיחות שנפתחו אחרי החיבור.
