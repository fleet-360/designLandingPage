חיבור {{agent.name}} ל-Claude.

עובדים על השרטוט הפתוח ב-AutoCAD מתוך שיחה ב-Claude. Pro Agent הוא תוסף שרץ בתוך AutoCAD, והמחבר נותן ל-Claude להשתמש בכלים שלו: לקרוא, לשרטט, לערוך ולייצא. לכן Pro Agent צריך להיות מותקן ומחובר במחשב שלכם.

מה צריך לפני שמתחילים

  • AutoCAD 2022–2027 ב-Windows, עם Pro Agent מותקן. להורדת Pro Agent. AutoCAD LT לא נתמך.
  • חשבון Pro Algorithm של החברה.
  • חשבון Claude בתוכנית שתומכת במחברים מותאמים (Pro, Max, Team או Enterprise), או Claude Code במסוף.

שלב 0: פותחים את Pro Agent ב-AutoCAD

  1. פותחים את AutoCAD ואת השרטוט שרוצים לעבוד עליו.
  2. מקלידים PROALGO כדי לפתוח את לוח Pro Agent.
  3. נכנסים עם חשבון החברה.

משאירים את הלוח פתוח כל עוד Claude עובד. כש-AutoCAD סגור או שלא נכנסתם, ל-Claude אין חיבור לשרטוט.

חיבור ב-Claude (אתר או אפליקציה)

  1. פותחים את ההגדרות. לוחצים על שם המשתמש בפינה, בוחרים Settings ואז Connectors.
  2. מוסיפים מחבר. גוללים לתחתית הרשימה ולוחצים Add custom connector.
  3. ממלאים את הפרטים. בשדה השם כותבים Pro Agent, ובשדה הכתובת מדביקים: 
    {{agent.mcp_server}}
    לוחצים Add. אין צורך למלא Client ID או Client Secret, השרת רושם את Claude בעצמו.
  4. מאשרים את הגישה. ליד המחבר החדש לוחצים Connect. נפתח חלון של Pro Algorithm בכתובת {{agent.mcp_authorize}}. נכנסים עם אותו חשבון חברה שאיתו נכנסתם ב-AutoCAD ומאשרים. Claude מתחבר רק לחיבורי AutoCAD של החברה שלכם.
  5. מפעילים בשיחה. פותחים שיחה חדשה, לוחצים על כפתור הכלים (+ או Search and tools) ומוודאים ש-Pro Agent מסומן. עכשיו אפשר לשאול, למשל: "אילו שכבות בשרטוט הפתוח לא עומדות בתקן שלנו?"

חיבור ב-Claude Code

במסוף, מתוך תיקיית הפרויקט:

claude mcp add --transport http pro-agent {{agent.mcp_server}}

מריצים claude, מקלידים /mcp, בוחרים pro-agent ואז Authenticate. הדפדפן נפתח לאותו חלון אישור, ואחרי האישור הכלים זמינים בשיחה.

מה Claude יכול לעשות דרך Pro Agent

  • לקרוא את השרטוט: שכבות, בלוקים, ישויות ואזורים שבחרתם.
  • לשרטט ולערוך, ולהריץ פקודות AutoCAD.
  • לחפש בתקני החברה ובמסמכי הפרויקט.
  • לזהות אלמנטים בשרטוט ולמצוא אלמנטים דומים.
  • לייצא לאקסל או CSV, להפיק דוחות PDF ולהדפיס ל-PDF.
  • לייבא בלוקים מהספריות שלכם.

השליטה נשארת אצלכם

  • ב-AutoCAD: במצב סקירה כל שינוי מופיע כהצעה בלוח Pro Agent, ואתם מאשרים או דוחים. שינוי שבוצע מתבטל ב-UNDO אחד.
  • ב-Claude: אפשר לקבוע לכל כלי אם הוא רץ אוטומטית או מבקש אישור בכל פעם.
  • סוכן אחד בכל רגע: כשהסוכן בלוח מטפל בבקשה, Claude לא יכול לבצע פעולות עד שהיא מסתיימת. כך שניהם לא עורכים את השרטוט בו-זמנית.

פתרון בעיות

  • "No AutoCAD session is connected". פותחים AutoCAD, מריצים PROALGO, נכנסים ומנסים שוב.
  • "No AutoCAD session signed in under your company". ב-Claude וב-AutoCAD נכנסים עם אותו חשבון חברה.
  • "The AutoCAD palette is running its own request". בקשה רצה עכשיו בלוח. מחכים שתסתיים ומנסים שוב.
  • Claude ממתין זמן רב. הצעה מחכה לאישור שלכם בלוח Pro Agent.
  • חלון האישור לא נפתח. הדפדפן חסם חלון קופץ. מאשרים חלונות קופצים ל-claude.ai ולוחצים Connect שוב.
  • שגיאת invalid_token או 401. ההרשאה פגה. ב-Settings, Connectors לוחצים על המחבר, Disconnect, ואז Connect מחדש.
  • הכלים לא מופיעים בשיחה קיימת. מחברים חדשים נטענים רק בשיחות שנפתחו אחרי החיבור.
